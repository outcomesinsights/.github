# outcomesinsights/.github

The organization-wide defaults for [Outcomes Insights](https://github.com/outcomesinsights).

- `profile/README.md` is the organization profile shown at github.com/outcomesinsights.
- Reusable workflows shared across the open-source gems will live under
  `.github/workflows/` once proven in a single repository first.

This repository is public because the gems that will call its workflows are public, and
a public repository cannot use a reusable workflow from a private one.
